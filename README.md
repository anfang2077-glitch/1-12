## 二、系统功能

- **管理员**：用户管理（增删改查/重置密码/禁用）、课程管理、全局数据概览。
- **教师**：课程与题库管理（单选/多选/判断/简答，批量导入）、组卷（逐题分值）、发布考试与指派考生、主观题阅卷、成绩统计（平均/最高/最低/及格率/分数段/题目正确率）。
- **学生**：查看指派考试、在线答题（倒计时、自动保存、断线恢复、超时自动交卷）、交卷判分、成绩与解析查看。

## 三、快速启动

### 1. 后端

```bash
cd code/server
npm install
cp .env.example .env          # 修改数据库连接
npm run db:init && npm run db:seed   # 建库建表 + 种子数据（需本机 MySQL 8）
npm run dev                   # http://localhost:3000
```

> 没有 MySQL 也可演示：`npm run start:memory` 以内存仓储启动（数据不持久化），便于答辩现场快速演示。

### 2. 前端

```bash
cd code/web
npm install
npm run dev                   # http://localhost:5173（已配置 /api 代理到 3000）
```
